# Objective Quality Evaluation of Point Clouds: Quality Features and Fusion Metrics

This repository contains the implementation and benchmarking framework for the paper:

> **Objective Quality Evaluation of Point Clouds: Quality Features and Fusion Metrics**

The work presents a comprehensive feature-level analysis of state-of-the-art full-reference point cloud quality metrics and proposes a novel fusion framework, named **Feature Selection Model (FSM)**, for objective point cloud quality assessment.

---

# Overview

Point cloud quality evaluation is essential for benchmarking and developing point cloud compression solutions. Existing hand-crafted metrics typically combine multiple geometry and color features, but the contribution and redundancy of individual features are rarely analyzed.

This work:

- Benchmarks **23 perceptual hand-crafted features** extracted from:
  - PSNR MSE D2
  - PSNR MSE YUV
  - PointSSIM
  - PCQM
  - GraphSIM / MS-GraphSIM

- Performs **Recursive Feature Elimination (RFE)** using:
  - Support Vector Regression (SVR)
  - Ridge Regression (RR)

- Proposes a feature fusion framework (**FSM**) using the most relevant features

- Evaluates the models across **five publicly available subjective quality assessment datasets**

- Analyzes generalization across:
  - Conventional codecs
  - Learning-based codecs
  - Multiple distortion types

The proposed models achieve competitive or superior performance compared to several state-of-the-art objective quality metrics.

# Proposed Feature Selection Model (FSM)

The proposed FSM combines the most relevant perceptual features extracted from existing metrics.

The best-performing configuration uses:

- PCQM features:
  - f2
  - f4
  - f5
  - f7

- MS-GraphSIM:
  - SIMmg Scale 0

- PSNR MSE D2

with **Ridge Regression**.

This configuration corresponds to:

```text
Model 5 (FSM)
```

The framework demonstrates that combining complementary geometry and luminance features leads to more robust quality prediction than using isolated metrics.

# Methodology

## 1. Feature Extraction

Features are extracted from reference and distorted point clouds using several state-of-the-art objective quality metrics.

## 2. Feature Ranking

Recursive Feature Elimination (RFE) is employed to identify the most relevant and least redundant features.

## 3. Regression

Selected features are fused using:
- Support Vector Regression (SVR)
- Ridge Regression (RR)

## 4. Validation

The models are evaluated using:
- PCC
- SROCC
- RMSE
- Outlier Ratio (OR)

# Main Findings

- Feature fusion consistently outperforms isolated metrics
- Geometry + luminance features provide the best trade-off
- A small subset of carefully selected features is sufficient to achieve high performance
- Ridge Regression provides highly stable performance across datasets
- Generalization decreases for unseen distortions such as:
  - Gaussian noise
  - Downscaling
- Nevertheless, the proposed FSM remains competitive across all evaluated datasets
